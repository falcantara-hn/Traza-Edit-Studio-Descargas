# TRAZA Edit Studio para Mac

Instaladores de TRAZA Edit Studio. Aquí no hay código.

## Instalar (recomendado)

Abre **Terminal** (Cmd+Espacio, escribe «Terminal», Enter), pega esta línea y presiona Enter:

```
curl -fsSL https://raw.githubusercontent.com/falcantara-hn/Traza-Edit-Studio-Descargas/main/instalar.sh | bash
```

Baja la última versión, la deja en Aplicaciones y la abre. Después la app se actualiza sola.

## Instalar con el archivo .pkg

[Descargar TRAZA-Edit-Studio.pkg](https://github.com/falcantara-hn/Traza-Edit-Studio-Descargas/releases/latest/download/TRAZA-Edit-Studio.pkg)

macOS lo va a bloquear porque la app no tiene firma de Apple. Después del aviso, ve a
**Ajustes del Sistema › Privacidad y seguridad**, baja hasta «Se bloqueó TRAZA-Edit-Studio.pkg»
y toca **Abrir igualmente**.
